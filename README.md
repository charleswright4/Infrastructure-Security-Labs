## How I Approach Every Project
1. **Define the goal** and what "success" looks like before touching anything.
2. **Build in isolation** using lab subscriptions and virtual environments, with cost controls on.
3. **Prioritize by risk**, not by whatever is easiest.
4. **Automate repeatable steps** with PowerShell or Bash.
5. **Verify with evidence** (scan results, logs, screenshots) instead of assuming it worked.
6. **Document for the next person**, so someone else could repeat or audit the work.
